# Портфолио Александра Мальцева

Статический одностраничный сайт-портфолио, подготовленный для публикации на GitHub Pages. Проект не требует backend, CMS, сборщика или внешних JavaScript-библиотек.

Публичный адрес: [https://zqaqzqaqsasha.github.io/portfolio/](https://zqaqzqaqsasha.github.io/portfolio/)

## Структура

```text
.
├── index.html
├── README.md
├── robots.txt
├── sitemap.xml
├── .nojekyll
└── assets
    ├── css
    │   └── main.css
    ├── js
    │   └── main.js
    └── images
        ├── alexander-maltsev.avif
        ├── favicon.svg
        └── og-image.png
```

## Запуск локально

В корне проекта выполните:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

Можно открыть `index.html` напрямую, но локальный сервер точнее воспроизводит поведение GitHub Pages.

## Изменение контента

- Тексты, ссылки и порядок секций находятся в `index.html`.
- Цвета, отступы, размеры, сетки и адаптивные правила находятся в `assets/css/main.css`.
- Мобильное меню, год в подвале и анимации появления находятся в `assets/js/main.js`.
- Базовые цвета собраны в CSS-переменных в начале `main.css`.

## Изображения и визуализации

Все публичные изображения хранятся в `assets/images/`.

Портрет подготовлен без ретуши и изменения лица: исходная фотография только пропорционально уменьшена и сохранена в AVIF как `assets/images/alexander-maltsev.avif`. Исходник в репозиторий не включен.

Визуализации пяти проектов собраны как компактные HTML/CSS-интерпретации интерфейсов. Они находятся непосредственно в `index.html`, а их оформление — в `assets/css/main.css`. Такой подход сохраняет читаемость и адаптивность макетов без тяжелых скриншотов.

OG-карточка находится в `assets/images/og-image.png` и имеет размер 1200×630 px. Favicon находится в `assets/images/favicon.svg`.

## Публичный адрес

Сайт публикуется из корня ветки `main` репозитория `zqaqzqaqsasha/portfolio` и доступен по адресу [https://zqaqzqaqsasha.github.io/portfolio/](https://zqaqzqaqsasha.github.io/portfolio/). Canonical URL, Open Graph, Twitter Card, `robots.txt` и `sitemap.xml` уже настроены на этот адрес.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Добавьте файлы проекта в корень репозитория и отправьте их в ветку `main`.
3. На GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. Дождитесь появления публичного адреса на этой же странице.
7. Внесите фактический адрес в SEO-файлы по инструкции выше и отправьте изменение в репозиторий.

Файл `.nojekyll` отключает обработку Jekyll. Все пути к ресурсам относительные, поэтому сайт работает и в корне домена, и в подпапке обычного репозитория GitHub Pages.

## Проверка после публикации

- Откройте все ссылки на публичные проекты и сайт «Территории Рязанская».
- Проверьте телефон, e-mail и Telegram.
- Проверьте меню и якоря на телефоне.
- Убедитесь, что OG-карточка доступна по публичному URL.
- Запустите Lighthouse в Chrome для финальной проверки Performance, Accessibility, Best Practices и SEO.

## Технологии

- семантический HTML5;
- современный CSS без препроцессора;
- небольшой vanilla JavaScript;
- AVIF для портрета и HTML/CSS-визуализации интерфейсов;
- адаптивность от 320 px;
- поддержка `prefers-reduced-motion`.
